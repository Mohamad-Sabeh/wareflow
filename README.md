# Wareflow

Wareflow is a warehouse management system built to manage products, inventory, orders, suppliers, customers, shipments, and reports.

## Features

* Dashboard with warehouse statistics
* Product management
* Inventory management
* Order management
* Shipment tracking
* Supplier management
* Customer management
* Reports
* User settings

## Tech Stack

* React
* JavaScript
* Vite
* Tailwind CSS
* React Router
* SQL
* Backend API

## Project Status

🚧 Currently in development.

The frontend and dashboard are currently being built. Database integration and backend functionality will be added as development continues.
